## Unity - Cube Puzzle

A digital version of the famous copyright protected cube puzzle that almost everyone knows but hardly anyone can solve.

[Test it on my website](https://www.karluwemartin.de/cubeGame/)

#### Usage

- Use mouse our touch to drag a section of the cube to rotate it by 90° andlong the desired axis. 
- Enable **Shuffle** to randomize the puzzle.
- Click **Reset** to reset the puzzle (careful - unsaved progress is lost)
- **Save/Load** stores or load the current state of the puzzle as JSON in the PlayerPrefs. In WebGL this data is stored in the browsers cache.

#### Technical Details

``` Unity Version: 6000.3.10f1 ```
Optimized for **WebGL** - but should also work on other platforms.
